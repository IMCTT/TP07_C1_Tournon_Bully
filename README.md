# Bully the Cannon

Sidescroller en el que controlás a Bully, un cañón con mucho carácter. Avanzá por el nivel, saltá los obstáculos y disparale a todo lo que se cruce en tu camino.

🎮 **Jugalo en Itch.io:** [link al juego](https://sueni.itch.io/bully) 

---

## 🎮 Controles

| Acción | Tecla |
|---|---|
| Mover izquierda | A |
| Mover derecha | D |
| Mover arriba | W |
| Mover abajo | S |
| Saltar | Espacio |
| Disparar | R |

---

## 🚀 Cómo correrlo localmente

1. Cloná el repositorio:  
2. Abrí el proyecto con Unity
3. Play.
